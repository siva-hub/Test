Welcome to your Playwright Practice Sandbox

This single-page application contains every real-world scenario you need to master automation with Playwright: complex inputs, dynamic waiting states, Shadow DOM, iFrames, drag-and-drop, custom modals, API mock endpoints, and token authentication.

1

Deploy to GitHub Pages

Push this single file as index.html into a new GitHub repository. Under repo Settings > Pages, select Deploy from Branch: main.

User-Centric Locators

Every element uses recommended Playwright attributes: getByRole, getByLabel, getByText, and getByTestId.

3

Zero Dependencies

Pure client-side JavaScript, mock backend simulation with delay toggles, full keyboard & touch support, and zero build tool requirement.
